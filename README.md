# Pysnake
Simple Snake game implemented in Python using `pygame`.

## Quick start

- Create a virtual environment (recommended):

```bash
python -m venv .venv
source .venv/bin/activate
```

- Install dependencies:

```bash
pip install -r requirements.txt
```

- Run the game:

```bash
python run.py
```

Controls:
- Arrow keys or WASD to move the snake
- On game over press `R` to restart or `Q` to quit

Notes:
- The game uses a simple grid and `pygame` for rendering. It may not run in headless containers without an X server.
